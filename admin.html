Newflix Admin
Monte o catálogo, crie usuários com canais e tempo de acesso, e publique o arquivo usuarios.js. Os links nunca ficam legíveis no repositório.

1. Catálogo de canais

Carregue suas listas M3U uma vez — o catálogo fica salvo neste navegador (os links ficam só com você, fora do GitHub).

2. Criar / atualizar usuário

Escolha os canais do catálogo que este usuário poderá ver e por quanto tempo.
Canais selecionados: 0

3. Usuários criados (nesta sessão)

4. Publicar — arquivo usuarios.js

Como publicar: copie o conteúdo, abra o arquivo usuarios.js no GitHub (botão ✏️ de editar), substitua tudo, cole e faça o commit. Os usuários entram no app com o login e a chave. Tempo de acesso: começa a contar no momento da geração; ao expirar, o app bloqueia automaticamente (mesmo assistindo). Para renovar, gere o usuário novamente com a mesma chave. Revogar: remova o usuário na seção 3 e publique.
